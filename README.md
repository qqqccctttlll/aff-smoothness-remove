# aff Smoothness Removal

Removes the **smoothness** argument from `arc(...)` statements in `.aff` files.

## Features

· Upload a single `.aff` or a `.zip` containing `.aff` files
· Automatically find `true,` or `false,` in each `arc(` line
· Delete the content from that comma to the first closing parenthesis on that line (keeping the closing parenthesis)
· Instantly download the processed file (single file or repackaged ZIP)

## Usage

1. Download `smoothnessRemove.html` from this repository
2. Open `smoothnessRemove.html`
3. Upload an `.aff` or `.zip`
4. The tool automatically processes and downloads the result:
   · Upload `.aff` → download `processed_original_filename.aff`
   · Upload `.zip` → download `processed.zip` (file names preserved)
