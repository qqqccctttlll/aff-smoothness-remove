# aff平滑度移除

删除`.aff`中`arc(...)`语句的**smoothness平滑度**参数。

## 功能

- 上传单个`.aff`或包含`.aff`的`.zip`
- 自动查找每一行`arc(`中的`true,`或`false,`
- 删除从该逗号开始到该行第一个右括号之间的内容（保留右括号）
- 即时下载处理后的文件（单文件或重新打包的 ZIP）

## 使用方法

1. 下载本仓库的`smoothnessRemove.html`
2. 打开`smoothnessRemove.html`
3. 上传`.aff`或`.zip`
4. 工具自动处理并下载结果：
   - 上传`.aff`→下载`processed_原文件名.aff`
   - 上传`.zip`→下载`processed.zip`（保留文件名）
